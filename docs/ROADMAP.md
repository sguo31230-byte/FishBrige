# 开发顺序

## v0.1（本次）
标准文本事件、范围白名单、SQLite 去重、保守恢复、演示适配器、自动测试。

## v0.2
DSH Responder 连接器：固定服务入口、模型超时、空正文检测、实际 usage 字段。
只记录接口真实返回的 token/cache 数据，缺失记 unavailable。

## v0.3
单一真实平台适配器。优先从微信现有代码中审查迁移可独立授权的模块，
不携带人格/聊天/密钥；先只读，再单会话发送，再故障恢复验收。
QQ 单独核验可用接入方式，不把微信 UI 坐标直接套用。

## v0.4
媒体附件、引用关系、跨平台能力矩阵、统一事件追踪、人工确认界面。
任何自动回复与主动发送权限分别配置。

## v1.0 门槛
至少一个真实适配器完成端到端与崩溃恢复测试；文档准确区分本机发送与远端收取；
连接器超时可取消；发布包不含用户数据。未满足前保持预览版。
